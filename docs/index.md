# Media Library Tools Documentation

Welcome to the complete documentation for **Media Library Tools** — a comprehensive WordPress plugin for media library management.

## Overview

Media Library Tools provides powerful features to help you manage, organize, and optimize your WordPress media library. The plugin is available in two versions:

- **Free Version**: Core media management features
- **Pro Version**: Advanced automation, AI integration, and additional tools

## Navigation

### Core Features
- [Media Settings](#media-settings) - Configure default metadata and behavior
- [Media Table](#media-table) - The main media management interface
- [Media Rename](#media-rename) - Bulk rename and manage file names

### Optimization & Utilities
- [Regenerate Thumbnails](#regenerate-thumbnails) - Rebuild image sizes for better compatibility
- [Image Sizes](#image-sizes) - Register and manage WordPress image sizes
- [Media Download](#media-download) - Download media files and organize exports

### Advanced Features
- [CSV Export/Import](#csvexportimport) - Bulk media operations with spreadsheets
- [Rubbish Files](#rubbish-files) - Find and clean up orphaned media files
- [Duplicates](#duplicates) - Detect and manage duplicate files
- [Used Where](#used-where) - Track image usage across your site

## Quick Start

1. **Install the Plugin**: Upload and activate Media Library Tools from your WordPress admin
2. **Configure Settings**: Visit the Settings tab to customize default metadata behavior
3. **Explore Features**: Use the sidebar menu to navigate different tools
4. **Pro Features**: Upgrade to Pro for AI-powered automation and advanced capabilities
