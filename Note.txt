**FEATURE 1 — Bulk Sync Engine**

- Process all images in the library in safe batches (not all at once)
- Before running, user can filter by:
  - Only images with missing EXIF date
  - Only images where EXIF and WP date do not match
  - A specific date range
- Show a progress bar while processing
- Show live count: "Processed X of Y"
- Allow user to cancel mid-way
- Show final results: how many synced, how many failed

---

**FEATURE 2 — Smart Sync Rules**

- On every upload, apply rules automatically (if enabled)
- Rule logic:
  - If EXIF date exists → use it
  - If EXIF missing → fallback options:
    - Try to extract date from filename
      (e.g. IMG_20240115.jpg → 2024-01-15)
    - Or use upload date
    - Or do nothing
- Timezone/offset correction:
  - User sets offset in hours (e.g. +3 or -5)
  - Applied to EXIF date before saving
- Bidirectional sync option:
  - Also allow writing WordPress date back to EXIF

---

**FEATURE 3 — Advanced Audit Dashboard**

- Scan all media and group images into categories:
  - EXIF matches WP date (all good)
  - EXIF exists but WP date is different (mismatch)
  - No EXIF at all
  - Future date (likely wrong camera date)
  - Duplicate timestamps (same date on multiple images)
- Show count per category with color indicators
- Show filterable image list per category
- Suggest fix for each category
- "Fix All" button per category

---

**FEATURE 4 — Undo and Activity Log**

- Log every date change: old date, new date, which image, who did it
- Show log in admin as a table with filters
- "Undo Last Bulk" button — reverts all changes from last bulk run
- Before any sync, backup the old date so it can always be restored

---

**FEATURE 5 — Export and Import**

- Export: download a CSV of all media with EXIF date and WP date
- Import: upload a corrected CSV and apply dates from it
- Show results after import: how many applied, how many failed

---

**FEATURE 6 — WooCommerce Product Image Support**

- Only activate if WooCommerce is installed
- Fix dates for all images in a product's gallery
- Add a "Fix Gallery Dates" button on the product edit screen
- Option to bulk fix all products at once

---

**FEATURE 7 — Reports Dashboard**

- Summary numbers: total images, images with EXIF, images synced,
  mismatches, last sync date
- Simple bar chart: how many images per year based on EXIF date
- Recent activity: last 10 changes from the log
- Quick action buttons to jump to bulk sync or audit
